# Security policy / 安全政策

## English

Do not report a vulnerability in a public Issue. Use **Security → Advisories → Report a vulnerability** so device-control, path-validation, archive, or command-injection findings can be reviewed privately.

Supported code is the current `main` branch. Reports should contain the affected commit, a minimal reproduction with fake serials and synthetic files, impact, and a suggested mitigation. Never attach real credentials, private device data, unlock tokens, keyboxes, or wallet material.

## 中文

不要在公开 Issue 中报告安全漏洞。请使用 **Security → Advisories → Report a vulnerability** 私密提交设备控制、路径校验、归档或命令注入问题。

当前支持范围是 `main` 分支。报告应包含受影响 commit、使用假 serial 和合成文件的最小复现、影响及建议缓解措施。不得附带真实凭据、设备私有数据、解锁 token、keybox 或钱包材料。
